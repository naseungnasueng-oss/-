## 받을 에셋 체크 범위

- 방 전체/기본 화면
- 문자 보드 확대 화면
- 캐비닛과 영문 자물쇠
- 앨범 빈 페이지/완성 페이지
- 서랍과 방향 자물쇠
- 더러운 거울/깨끗한 거울
- 달력과 출구
- 움직인 쿠션, 잡지, 액자, 열린 TV장 수납부
- 문자 아이템 `L`, `B`, `U`, `M`
- 휴지, 학생 면담 통지서, 완성된 오래된 사진
- 자물쇠·달력 조작 화살표 및 선택 효과

수신이 끝나면 해상도·투명도·중복·상태별 구도를 확인한 뒤 `Assets/Art/Room3/` 아래의 실제 Unity용 구조로 선별 복사합니다.
